# Tecnologias e Ferramentas

| Categoria | Tecnologia | Justificativa |
|:---------:|:----------:|:--------------|
| Mobile (Fornecedor/Produtor/Logística) | React Native / Expo | Desenvolvimento híbrido iOS/Android com alta *performance* e agilidade. |
| *Frontend* (Logística/Admin) | React.js (Web) | Ideal para *dashboards* complexos, mapas interativos e SPAs com renderização rápida. |
| *Backend* | Node.js | Arquitetura modular, TypeScript nativo e alta escalabilidade. |
| Banco Relacional | PostgreSQL + PostGIS | Dados estruturados com suporte a consultas geoespaciais para otimização de rotas e localização de fornecedores. |
| Banco NoSQL / Cache | Redis | Cache de buscas (RNF02) e gerenciamento de sessões em tempo real. |
| Infraestrutura / Cloud | AWS (Lambda + S3) | *Auto-scaling serverless* e armazenamento criptografado de certificados e fotos de resíduos. |
| Pagamentos | Stripe API | Integração simplificada de PIX, cartões de crédito, débito e boleto bancário (RF10). |
| Geolocalização | Google Maps / Mapbox | Otimização de rotas de coleta e entrega, geolocalização de fornecedores e compradores (RF15). |
