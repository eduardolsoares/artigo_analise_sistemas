# Glossário {-}

**API**
: *Application Programming Interface*, conjunto de rotinas e padrões para integração entre sistemas.

**CONAMA**
: Conselho Nacional do Meio Ambiente, órgão consultivo e deliberativo do SISNAMA, responsável por estabelecer normas e padrões ambientais no Brasil.

**EAP**
: Estrutura Analítica do Projeto, decomposição hierárquica do trabalho a ser executado pela equipe.

**Economia circular**
: Modelo econômico que visa eliminar o desperdício e o uso contínuo de recursos, promovendo o reaproveitamento e a reciclagem de materiais.

**JWT**
: *JSON Web Token*, padrão de autenticação para transmissão de dados entre partes.

**LGPD**
: Lei Geral de Proteção de Dados (Lei nº 13.709/2018), legislação brasileira que regula o tratamento de dados pessoais.

**MoSCoW**
: Método de priorização que classifica requisitos em *Must Have*, *Should Have*, *Could Have* e *Won't Have*.

**MVP**
: *Minimum Viable Product* (Mínimo Produto Viável), versão do produto com funcionalidades mínimas para ser lançada e validada.

**PostGIS**
: Extensão geoespacial para o banco de dados PostgreSQL, que permite armazenar e consultar dados de localização geográfica.

**RBAC**
: *Role-Based Access Control*, modelo de controle de acesso baseado em funções.

**Rastreabilidade**
: Capacidade de rastrear e documentar o caminho percorrido por um produto ao longo da cadeia produtiva, desde a origem da matéria-prima até o produto final.

**Resíduos orgânicos**
: Material biodegradável proveniente de origem vegetal ou animal, como restos de alimentos, cascas de frutas, podas de jardim e subprodutos agroindustriais.

**REST**
: *Representational State Transfer*, estilo arquitetural para serviços web.
