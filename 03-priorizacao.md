# Priorização de Requisitos

A priorização define a ordem de desenvolvimento para o MVP (Mínimo Produto Viável), seguindo o modelo MoSCoW.

**Must Have (essenciais para o MVP)**
: RF01 (Cadastro de Produtos pela Loja), RF02 (Cadastro de Usuários), RF04 (Carrinho), RF05 (Compra/Checkout), RF06 (Pagamento com Cartão), RF07 (Pagamento via PIX), RF08 (Pagamento via Boleto), RF09 (Cálculo de Frete), RF13 (Visualização de Vendas), RNF01 (Segurança/LGPD), RNF06 (Rastreabilidade)

**Should Have (importantes, mas podem esperar o pós-lançamento imediato)**
: RF10 (Status do Pedido), RF11 (Rastreamento de Pedido), RF14 (Validação de Produtos)

**Could Have (desejáveis se houver recursos excedentes)**
: RF12 (Notificações de Entrega), RF15 (Gestão de Disputas), RF16 (Histórico de Compras), RF17 (Avaliação de Produtos)

**Won't Have (ficará para versões futuras/longo prazo)**
: Marketplace de insumos agrícolas integrado, Otimização de processamento por inteligência artificial, Programa de certificação orgânica digital integrado

## Sequenciamento das Etapas do Projeto

| Fase | Descrição |
|:---|:---|
| Fase 1 – Funcionalidades Essenciais (MVP) | Comprar produto; Cadastro do produto por parte da loja; Receber pagamento |
| Fase 2 – Gestão e Acesso Básicos | Permite a loja ver as vendas realizadas; Navegação dentro do site; Cadastro de usuários |
| Fase 3 – Checkout & Exibição de Estoque | Calcula frete da entrega de acordo com o CEP; Pagamento via cartão de crédito ou débito; Mostrar produtos no estoque |
| Fase 4 – Rastreamento & Experiência de Compra | Possibilita rastreamento da entrega do produto; Pesquisa de produtos; Adicionar produto ao carrinho |
| Fase 5 – Relacionamento, Notificações & Estoque | Espaço para avaliação do produto pelos usuários; Notificação da entrega do produto; Reserva de estoque para o cliente |
